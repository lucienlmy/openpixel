# 活拼图

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/living-jigsaw/) · [源码文件](source.js)

从多块拼装到画面活过来，路通后车辆前进。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

绿色桌布上摊着一盒六十片的拼图，画的是夏天下午的海边小镇。一片一片拼上去：先拼边框，再拼中间。拼上去的块会动起来，云在飘，海在闪光，船在走；还散在桌上的块是静止的。画里的东西只能在拼好的地方走动，帆船、渡轮、公交车和一群鸟碰到还缺着的那一块就停下来等。公交车在路中间一直等着最后那一块。一只手把最后一块按下去，公交车开走了，灯塔亮了，屋子里的灯也亮了，拼缝慢慢淡掉，整幅画成了一个完整的、活着的小镇。然后拼图被拆开，从头再来。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 222 行附近，可搜索 `jigsaw` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
