# 沙丁鱼风暴

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/sardine-storm/) · [源码文件](source.js)

鱼群受海豚扰动聚合，观察整体运动。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

开阔的蓝色海水，头顶是晃动的水面，阳光一道道斜射下来。一千四百条沙丁鱼像一个整体在游，你是那只海豚。 手指拖到哪儿，海豚就游到哪儿：鱼群在你身边被撕开，每一条在转身侧过来时都会被阳光照出一闪银光。绕着它们转圈，鱼会挤成一个转个不停的鱼球；点一下海豚猛冲，鱼球像烟花一样炸开。不管它们，鱼群又会慢慢合成一条缓缓流动的河。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 213 行附近，可搜索 `sardines` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。

- 这是效果和玩法实验，不是完整商业游戏；原作的自动演示、随机性与简化碰撞仍保留。
