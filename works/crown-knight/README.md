# 断冠骑士

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/crown-knight/) · [源码文件](source.js)

多机位首领战，翻滚、硬直、处决与布料。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

同一场首领战，五个机位：骑士背后锁定、侧面、断冠骑士的肩后（王的视角）、高处俯瞰、绕场自由环绕。默认由“自动导演”按战况切镜：横扫切到侧面，飞刃切到王的视角，跃击切到俯瞰，咆哮切到低机位仰望，处决给特写；也可以在上方“镜头”里固定任一机位，或按 V 轮换。 没有三维模型。两个人物只有一副骨架：骨架给出每个关节在场景里的位置，头盔、胸甲、肩甲、护膝、盾、剑都按当前机位逐像素重新上色，用手挑的色阶分层，描暗边和金色逆光边，不用抖动。椭圆部件带着自己的表面坐标，所以面甲缝、胸前的太阳纹、盾面的彩绘转到哪一侧都在原位。披风是布料模拟，按褶皱逐像素上色，看到里衬时换成暗色。 光是真实方向：太阳在巨树右侧偏低，镜头朝着太阳时人物逆光、只剩金边，转到首领身后变成正面受光。首领有延迟下砸、横扫、跃击、光刃和二阶段咆哮；骑士可以翻滚、两段轻攻击、重攻击、喝药，打满架势后上前处决，击败后首领从脚下化成金光消散。方向键按当前镜头的方向移动。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 1324 行附近，可搜索 `souls` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。

## 本辑的边界

- 这是效果和玩法实验，不是完整商业游戏；原作的自动演示、随机性与简化碰撞仍保留。
- 优先在桌面浏览器体验；触摸能力以原作控件为准。战斗和驾驶场景的完整操作需要键鼠。
- 系统字体会影响部分文字的外观。本辑使用本地字体回退，不下载在线字体。
- 为便于独立打开，公共运行代码随本作品附带。该页只注册本作品，其他未入选作品的注册块已移除。
