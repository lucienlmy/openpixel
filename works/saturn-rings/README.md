# 土星环

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/saturn-rings/) · [源码文件](source.js)

投放卫星，观察近轨道碎裂与成环。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

黑暗里悬着一颗有条纹的气态巨行星，光从右边照过来，我们稍微从轨道平面上方看着它。甩出一颗卫星，它会绕着行星转。 要是离得太近、进了虚线那圈洛希极限，潮汐会把它拉长、撕裂成几千块碎片；接下来的一分钟里，碎片沿着轨道被拉开，慢慢铺平成一条薄薄的光环，背阴那一段还落着行星的影子。直直甩向行星就是一次撞击。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 207 行附近，可搜索 `rings` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。

- 这是效果和玩法实验，不是完整商业游戏；原作的自动演示、随机性与简化碰撞仍保留。
