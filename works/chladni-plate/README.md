# 克拉尼板

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/chladni-plate/) · [源码文件](source.js)

振动频率改变粒子形成的结线图案。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

聚光灯下一块装在立柱上的黑钢板，上面撒着一层细沙。按住板子就像用琴弓拉它：板子响起来，在振动的地方沙子一直跳、往旁边蹦，跳到不动的线上就停下，一个克拉尼图形就自己画出来了。 按的位置决定音高：越靠中间音越低、图形越简单，越靠边越高、越复杂。按着滑动，音一变，沙子就从一个图形慢慢流向下一个。点一下是撒一把沙。可以换成黄铜板配深色沙，或者蓝钢。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 197 行附近，可搜索 `chladni` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
