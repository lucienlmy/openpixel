# 星系相撞

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/galaxy-collision/) · [源码文件](source.js)

双星系接近，恒星轨迹拉成长尾。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

两个旋涡星系在几亿年里相遇、擦身而过、再被引力拉回来合并成一个。画面里 14000 个点各自按两个星系核的引力实时计算轨道（Toomre 兄弟 1972 年用的那种受限多体模型），所以那两条长长的潮汐尾和中间的恒星桥不是画出来的，是算出来的；我负责的是把每个像素的恒星密度分成六级平涂色带，蓝色属于一个星系、金色属于另一个，混在一起的地方是淡紫色。气体被挤压的地方会突然点亮粉色的恒星形成区。镜头在相撞过程中慢慢绕行并拉远。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 104 行附近，可搜索 `galaxy` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。

## 本辑的边界

- 这是效果和玩法实验，不是完整商业游戏；原作的自动演示、随机性与简化碰撞仍保留。
- 优先在桌面浏览器体验；触摸能力以原作控件为准。战斗和驾驶场景的完整操作需要键鼠。
- 系统字体会影响部分文字的外观。本辑使用本地字体回退，不下载在线字体。
- 为便于独立打开，公共运行代码随本作品附带。该页只注册本作品，其他未入选作品的注册块已移除。
