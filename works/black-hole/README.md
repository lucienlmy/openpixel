# 黑洞

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/black-hole/) · [源码文件](source.js)

吸积盘与透镜视觉，参数化生成宇宙场景。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

一个四千万倍太阳质量的黑洞，周围是绕它旋转的吸积盘。我们从盘面上方稍高一点的地方看过去，所以本来在黑洞背后的那一半盘子，被引力把光弯过来，像一道光环架在黑洞的上方和下方；紧贴黑色阴影的那一圈细亮线，是绕着黑洞转了几乎一整圈才逃出来的光。左边的气体朝我们奔来，被多普勒效应提亮成白色，右边远去的一侧暗成深红。内圈转得比外圈快，所以纹理会被慢慢剪切成一圈圈的细丝。背景的星星在缓慢移动，经过黑洞边缘时会被拉成弧线、一分为二。每一帧都是按广义相对论把每个像素的光倒着追回去算出来的。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 121 行附近，可搜索 `hole` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
