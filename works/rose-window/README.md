# 哥特玫瑰窗

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/rose-window/) · [源码文件](source.js)

彩色玻璃和地面的投影随光变化。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

站在一座哥特大教堂的十字交叉处，看横厅墙上的玫瑰窗：中心是金色圆窗，外面一圈十二片花瓣，再外面是二十四个小圆窗，石头窗棂把玻璃分成一格一格，以沙特尔大教堂那种深蓝为主，夹着宝石红、金和绿。窗下五扇尖顶窗里各站着一位圣徒。太阳从窗后右上方照进来，在昏暗的空气里打出几道光柱，地上那块彩色光斑真的是玫瑰窗的倒影：每个地面像素都去找它头顶对应的那块玻璃，取一半颜色，所以花瓣和圆窗会上下颠倒地印在石板和椅背上，并随着太阳慢慢移动。云飘过去时光线一级一级暗下去又亮回来，玻璃的亮度也跟着变。一位朝圣者走进来点了一支蜡烛，跪下祈祷，再起身离开。60 秒一圈。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 181 行附近，可搜索 `cathedral` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
