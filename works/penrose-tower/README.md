# 永登之塔

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/penrose-tower/) · [源码文件](source.js)

转动视角，揭示看似无限上升的楼梯。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

一座修道院的屋顶是一圈台阶，一队修士顺时针一直往上走，另一队逆时针一直往下走，谁都走不到头。这不是画出来的错觉贴图：塔是一个真实的三维螺旋，绕一圈升高 27 格，同时朝我们靠近 27 格，在这个等距视角下这两段位移刚好抵消，所以首尾在屏幕上严丝合缝。光影、遮挡、投影全部是按这个三维形体逐像素算出来的。拖动下面的「转动视角」，镜头一偏，首尾就会错开，露出它其实是一段螺旋，修士走到接缝处会瞬移；回到正位，它又闭合成一圈。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 226 行附近，可搜索 `stairs` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
