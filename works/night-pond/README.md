# 夜池

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/night-pond/) · [源码文件](source.js)

点水扭曲倒影，投食让锦鲤靠近。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

夏夜的庭院：对岸有红色的太鼓桥、亮着灯的亭子、石灯笼和柳树，池水把这一切倒映出来。把手停在水面上，锦鲤会慢慢游到你手下面；点一下水面，撒下几粒鱼食，最近的那条会浮上来一口吞掉；按住拖动，就是用手指在水里划。 水面是一张波动场，每帧按波动方程推进。每个水面像素都沿着波面的坡度去查倒影，所以一圈涟漪会把月亮打碎成一片碎光，把桥拉弯。水下的锦鲤用一条会弯的脊椎游动，越靠近水面越清楚。睡莲叶随波浮动，萤火虫在水里也有倒影。下雨时整池都是雨圈。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 315 行附近，可搜索 `pond` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
