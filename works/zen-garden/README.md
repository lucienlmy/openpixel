# 枯山水

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/zen-garden/) · [源码文件](source.js)

拖动耙砂，保留高度场与光影的变化。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

从寺院的檐廊往外看：土墙、瓦顶、石灯笼、竹筒添水，一片白砂和五块石头。按住画面拖动，耙子就跟着你的手在白砂上走，五根耙齿犁出五道沟，沟顺着你的笔画转弯。轻点一块石头，耙子会绕着它画出一圈圈同心纹。 白砂是一张高度图，每个像素每帧按自己的坡度重新受光：朝着太阳的砂脊亮，背阴的沟暗，所以同一道纹在清晨、正午、黄昏看起来都不一样，到夜里只剩石灯笼照亮的一小片。石头按块面打光，影子随太阳转。枫叶会落下来，耙子会把它们推开。下雨时雨点一点点把沙纹抹平，砂和石头被打湿变暗。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 453 行附近，可搜索 `zen` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
