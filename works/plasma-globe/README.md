# 等离子球

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/plasma-globe/) · [源码文件](source.js)

手指聚拢电弧，切换电光颜色。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

黑屋子的桌上放着一只等离子球。紫色的电光从中间发亮的核心爬向玻璃，一边分叉一边闪。 手指按上玻璃，所有电光都会甩过来，汇成你手指下一根又粗又亮的电弧，噼啪响、溅火星；沿着球面拖，电弧跟着走；松手又四散开。点一下是一道闪光。光会洒到墙上、桌面和玻璃边上，核心跟着嗡嗡声一明一暗。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 217 行附近，可搜索 `plasma` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
