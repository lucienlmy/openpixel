# 冰裂

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/cracking-ice/) · [源码文件](source.js)

按压裂冰，观察应力线与碎裂传播。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

从正上方看一片结了黑冰的湖，上面落着一层薄雪。拖动是扫雪：雪粉朝你扫的方向飞出去，落在别处又积起来，扫开的地方露出冰里冻住的东西：一串串白色的气泡、一片枫叶、几根草，还有一条锦鲤在冰下慢慢游。 点一下是敲冰：裂纹从敲的地方放射出去，一边跑一边分叉，碰到别的裂纹就停下，再连成一圈圈环形；同时冰面发出那种从高到低、像激光一样的回响。按住不放，裂纹会一次次加长，最后黑色的湖水从缝里涌上来，顺着裂纹渗开，把雪泡成灰色。鱼听到敲击会吓得游走。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 230 行附近，可搜索 `ice` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
