# 光绘

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/light-painting/) · [源码文件](source.js)

光轨累积、空间旋涡与加色光晕。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

夜里的海滩，相机架在三脚架上，快门一直开着。按住拖动就是挥一根点着的烟花棒：白热的火头拉出一条光带，分叉的火星划出细细的金线，而且不会马上消失，因为底片一直在收光。换成彩光棒，光带会一路变色。 按住不动，就开始甩一团燃烧的钢丝棉：一个橙色光球，火星沿切线甩出去，落到湿沙上再弹起来。湿沙把你画的一切倒映出来，浪一次次冲上来又退下去，重新把沙子打湿；天上的星星慢慢拉成弧线，远处灯塔在转。点“新底片”，快门合上，重新开始一张。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 273 行附近，可搜索 `lightpaint` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。

## 本辑的边界

- 这是效果和玩法实验，不是完整商业游戏；原作的自动演示、随机性与简化碰撞仍保留。
- 优先在桌面浏览器体验；触摸能力以原作控件为准。战斗和驾驶场景的完整操作需要键鼠。
- 系统字体会影响部分文字的外观。本辑使用本地字体回退，不下载在线字体。
- 为便于独立打开，公共运行代码随本作品附带。该页只注册本作品，其他未入选作品的注册块已移除。
