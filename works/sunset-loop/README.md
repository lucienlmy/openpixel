# 落日环线

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/sunset-loop/) · [源码文件](source.js)

追尾视角、道路透视与落日光照。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

黄昏的乡间环线：嘉年华拱门下发车，六辆车跑一圈两公里半，穿过收割后的麦田和树篱、爬上山脊飞过坡顶、沿着湖边直道冲进落日、在秋天的林子里连续过弯。镜头在车后，像地平线系列那样跟着车身摆动，速度越快视野越宽。 地面每一列像素从近到远逐个采样：路面、标线、弯道路肩、田块的割痕和犁沟、树篱、落叶层、岩石、湖岸的沙都是按世界坐标现画的，用手挑的黄昏色阶分层，没有抖动。太阳很低，山坡和树都投出几十米长的影子；湖面倒映着天空，太阳下面是一条碎金。 车不是贴图：车身按截面放样成曲面，每个像素按它在车上的位置上色——尾灯灯带、车牌、扩散器、双排气、车顶条纹、车窗里的晚霞、轮辋和粉色卡钳，刹车时尾灯更亮，换挡时排气管喷火。树、观众、热气球都按当前大小单独画，逆光时树冠只剩一圈金边。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 1255 行附近，可搜索 `horizon` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。

## 本辑的边界

- 这是效果和玩法实验，不是完整商业游戏；原作的自动演示、随机性与简化碰撞仍保留。
- 优先在桌面浏览器体验；触摸能力以原作控件为准。战斗和驾驶场景的完整操作需要键鼠。

- 为便于独立打开，公共运行代码随本作品附带。该页只注册本作品，其他未入选作品的注册块已移除。
