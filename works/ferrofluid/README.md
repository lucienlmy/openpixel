# 磁流体

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/ferrofluid/) · [源码文件](source.js)

移动磁场，控制黑色液体的尖峰与反光。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

白色玻璃桌上一摊黑色的磁流体，头顶一盏柔光箱。你的指针是藏在桌子下面的磁铁。移过去，液体会慢慢朝它爬；按住，磁场变强，液面一下子竖起一圈六角形排列的尖刺，正对磁铁的那根最高；按着移动，整团液体带着刺追过去。 松手，刺就融回去，又变成一面黑镜子。液体像镜子一样只反射周围：朝上的面映出黑天花板和柔光箱，陡峭的侧面映出白桌子。可以换成霓虹灯，刺尖会映出粉色和青色。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 193 行附近，可搜索 `ferro` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
