# 霜窗

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/frost-window/) · [源码文件](source.js)

擦除霜花，观察玻璃水珠与霜的再生。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

雪夜，一间黑着灯的屋子，窗台上点着一支蜡烛。六格木窗上结满了霜，窗外是合掌造的雪村，家家户户亮着灯。按住画面拖动，就是用指尖在玻璃上化霜，可以擦出一个看窗外的圆洞，也可以写字、画画。 化掉的霜会变成水，聚成水珠顺着玻璃往下淌，淌过的地方留下一道透明的痕，水珠流尽就冻成一颗小冰珠。霜不会就此退走：羽毛状的霜花从你擦出的边缘重新长进来，按六十度分叉，慢慢把你写的字盖住。哈一口气，玻璃上会起一层雾；杯子的热气也会把上方的玻璃熏模糊。蜡烛把附近的霜照成暖色。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 319 行附近，可搜索 `frost` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
