# 拉坯

[▶ 在线体验](https://ma1902056219-coder.github.io/openpixel/works/pottery/) · [源码文件](source.js)

拉坯塑形，观察轮廓、旋转与材质。

## 打开和操作

双击本目录的 `index.html`，或从[合集首页](../../index.html)进入。页面保留原作的自动演示及操作控件，点击画布后接管。

陶工的转盘上有一团泥。先用两手扶稳，再一圈圈往上拉，拉成师傅画好的样子：一只碗，一只梅瓶，一只玉壶春。 泥拉得太薄会裂，一圈比下一圈凸出太多会塌。做好了切口、上釉、进窑，开窑才知道成色：青瓷开片，天目油滴，钧窑紫斑。

## 修改一个自己的版本

1. 复制整个本目录，保留 `index.html` 和 `source.js` 在同一级。
2. 用文本编辑器打开 `source.js`。作品注册/说明位于第 314 行附近，可搜索 `pottery` 或作品名定位。
3. 先改变作品段落里的颜色或一个数值，保存后刷新浏览器，确认变化，再调整动作和交互。
4. `init` 负责初始状态，`tick` 更新状态，`draw` 绘制画面。公共绘制和播放代码也收在此文件中，修改时保留依赖关系。
