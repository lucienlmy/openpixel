# 작품 조작 안내

루트의 작품 모음이나 표시된 파일을 로컬에서 여세요. 작품 내 UI와 대조할 수 있도록 중국어 원제도 함께 적었습니다. 데모와 재생은 각 작품 페이지에 표시되는 컨트롤을 이용하세요.

<a id="night-pond"></a>

## 밤의 연못 / 夜池

물결로 반사상을 흔들고 비단잉어에게 먹이를 주세요.

수면 위에 포인터를 두면 비단잉어가 다가옵니다. 클릭하면 먹이와 물결이 생기고, 누른 채 드래그하면 물을 휘저을 수 있습니다.

- 로컬 실행 파일: `works/night-pond/index.html`
- [수정할 소스](../works/night-pond/source.js)

누른 채 드래그해 돌고래를 움직입니다. 물고기 떼 주위를 돌면 물고기가 모이고, 클릭하면 돌고래가 돌진합니다.

<a id="crown-knight"></a>

## 왕관을 잃은 기사 / 断冠骑士

회피, 경직, 카메라 전환이 있는 보스 전투.

방향키: 이동. J: 약공격, L: 강공격, K 또는 Space: 회피, U: 회복, V: 카메라 전환. 자유 회전 모드에서는 N과 M으로 카메라를 돌립니다.
