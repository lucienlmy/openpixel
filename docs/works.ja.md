# 作品の操作説明

ルートの作品集、または記載したファイルをローカルで開いてください。作品内の表示と照合できるよう、中国語の原題を併記しています。デモや再生の操作は、それぞれのページに表示されるコントロールを使ってください。

<a id="night-pond"></a>

## 夜の池 / 夜池

波紋で映り込みを揺らし、錦鯉に餌をあげる。

水面にポインターを置くと錦鯉が寄ってきます。クリックで餌と波紋、押したままドラッグすると水をかき混ぜられます。

- ローカルの実行ファイル: `works/night-pond/index.html`
- [編集するソース](../works/night-pond/source.js)

<a id="sardine-storm"></a>

## イワシの嵐 / 沙丁鱼风暴

イルカを動かして、渦を巻く魚群をかき分ける。

押したままドラッグしてイルカを動かします。魚群の周りを回ると魚が集まり、クリックするとイルカが突進します。

- ローカルの実行ファイル: `works/sardine-storm/index.html`
- [編集するソース](../works/sardine-storm/source.js)

自動ズームを眺めるほか、画面を左右にドラッグしてカメラを進めたり戻したりできます。

- ローカルの実行ファイル: `works/endless-window/index.html`
- [編集するソース](../works/endless-window/source.js)

<a id="crown-knight"></a>

## 失冠の騎士 / 断冠骑士

回避、体勢崩し、視点切り替えのあるボス戦。

矢印キー：移動。J：弱攻撃、L：強攻撃、K または Space：回避、U：回復、V：カメラ切り替え。自由旋回モードでは N と M でカメラを回せます。

- ローカルの実行ファイル: `works/crown-knight/index.html`
- [編集するソース](../works/crown-knight/source.js)

<a id="sunset-loop"></a>

## サンセット・ループ / 落日环线

夕日へ向かって走る、後方視点のドライブ。

↑：アクセル、↓：ブレーキ、← →：ハンドル。K または Space：ハンドブレーキでドリフト。V：カメラ切り替え。

- ローカルの実行ファイル: `works/sunset-loop/index.html`
- [編集するソース](../works/sunset-loop/source.js)

<a id="jellyfish"></a>

押したままドラッグして海水をかき混ぜます。クラゲをクリックすると光って逃げ、周囲にも反応が広がります。押したまま静止すると、光る指先へ集まります。

- ローカルの実行ファイル: `works/jellyfish/index.html`
- [編集するソース](../works/jellyfish/source.js)

<a id="pottery"></a>

## ろくろ / 拉坯

回るろくろの上で、粘土の形を整える。

ポインターで手の位置を動かし、押して粘土に触れます。上へ引くと高く薄くなり、左右で形を整えます。矢印キーでも移動でき、J を押して粘土に触れます。K は手が口縁より下なら切り離し、上なら焼成へ進みます。

- ローカルの実行ファイル: `works/pottery/index.html`
- [編集するソース](../works/pottery/source.js)

<a id="kintsugi"></a>

## 金継ぎ / 金缮

欠片を合わせ、漆、金粉、磨きの工程を進める。

ポインターか矢印キーで移動。J で欠片を持つ・置く、K を押したまま回転。後の工程では J を押して漆・金粉・磨きを行い、K で次へ進みます。

- ローカルの実行ファイル: `works/kintsugi/index.html`
